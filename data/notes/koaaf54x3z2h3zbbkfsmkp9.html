Data on the Web Best Practices

Intended to treat the web as a medium for exchange of data. Data publishers need to be able to control access to data and publish it, and Data consumers want to find resources, via links. There is a need for these two groups to have an agreed usage.

Soem data does need to be restricted and security measures are necessary.

Standards are needed for following best practices online.

Scope for best practices:

  • specifically relevant to data published on web
  • encourage publication or reuse data on the web
  • testable by machine, human or both

Best Practices

Benefits, which represents an improvement to dataset availability methods, and a best practice can have more than one benefit:

  • Reuse
  • Comprehension
  • Linkability
  • Discoverability
  • Trust
  • Access
  • Interoperability
  • Processability

They reference 35 best practices. The highlights revolve around providing metadata that is useful, version info, URIs for datasets, emphasis on machine readability, and following IP/licensing rules.
