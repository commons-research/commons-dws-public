HTTP range requests

A Range request asks the server to send parts of a resource back to a client. Useful for streaming.

Checking if a server supports partial requests

If server includes Acept-Ranges header wiht any value besides None then it does support them.

can check with curl -I [url to file]. if it has something like accept-ranges: bytes then it can be streamed as bytes!

This does also mean that ranges can be requested to (such as for a partial stream of the resource).

Range Header

The Range request header indicates the part of the resource the server should return. Server is able to send back partial requests of resources, and if not enabled will ignore the Range header and send back the whole request. Ignoring the Range is the same as Accept-Ranges: none and therefore streaming is not possible from that server. Range uses bytes, zero indexed for the range. Check if server supports Range: curl -v --http1.1 -I [url to file] and if possible see: Accept-Ranges: bytes.
