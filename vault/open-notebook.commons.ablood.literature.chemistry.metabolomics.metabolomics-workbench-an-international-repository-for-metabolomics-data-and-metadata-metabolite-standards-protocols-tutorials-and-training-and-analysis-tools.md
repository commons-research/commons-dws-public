# [Metabolomics Workbench: An international repository for metabolomics data and metadata, metabolite standards, protocols, tutorials and training, and analysis tools](https://academic.oup.com/nar/article/44/D1/D463/2502588)

DRCC (Data Repository and Coordinating Center) has developed a Metabolomics Workbench, for analyzing tracking depositing and disseminating large volumes of data from metabolomics studies from RCMRC (Regional Comprehensive Metabolomics Resources Cores). 
## Database content and description
### metadata and experimental data
The MSI (metabolomics standards initiative) has recommendations for minimum metadata reporting standards. They used Excel for the metadata tracking. 

The data they have collected is browsable and viewable. Along with a searchable metabolites structure database. https://www.metabolomicsworkbench.org/ -> still iln use today and updated.
