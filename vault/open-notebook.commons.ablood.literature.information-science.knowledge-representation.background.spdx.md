# [SPDX](https://spdx.dev/)
SPDX has a specification, license list, and tools and libraries available for working with it. 
## Guiding Principles
- formats are human and machin readable
- focus on collecting and communicating facts
- does not do legal interpretations
- facilitates metadata exchange in supply chain
## [Specification](https://spdx.dev/wp-content/uploads/sites/31/2024/12/SPDX-3.0.1-1.pdf)
Metadata includes details about creation/distribution including:
- software composition, including packages used
- software build info
- AI models
- datasets
- creator, supplier and distributor
- provenance and integrity
- licenses and copyrights
- security vulnerabilities, defects, quality issues
- relationships between system elements
- software usage and lifecycle
- mechanisms to enable SPDX element annotation and linking SPDX docs
