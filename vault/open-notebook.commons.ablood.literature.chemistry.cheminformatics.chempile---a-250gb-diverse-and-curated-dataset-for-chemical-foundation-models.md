# [ChemPile - A 250GB Diverse and Curated Dataset for Chemical Foundation Models](https://arxiv.org/abs/2505.12534)
This dataset has been curated to work with foundation models. Data content types are organized into different subsets:
- Education: core knowledge for educational content
- Paper: curated scientific literature based chemical content, for learning from frontier science
- (m)Lift: tabular language based interface, with different chemical representations including InChI
- Reasoning: Has reasoning tracing for chemical problems
- Code: Chemical code
- Caption: Pairs of chemical images with text descriptions
Thus the core features of the dataset are:
- Scale: largest open curated chemical corpus
- Expert curation: cleaned and annotated. not raw data
- Content type diversity: (mentioned above, edu, paper, etc)
- Chemical Diversity: spans biochem, materials science, 
- Multimodal: images, captions, molecular representations, all in different formats
- Ease of use: hosted on hugging face with permissive licence
