# [Semantic Web Development Tools (Wiki)](https://www.w3.org/2001/sw/wiki/Tools)
## Terms
* **[Semantic Web](https://en.wikipedia.org/wiki/Semantic_Web)**: Extension of the Web where data is structured so it can be interpreted and linked computationally.
* **[RDF](https://en.wikipedia.org/wiki/Resource_Description_Framework)**: Resource Description Framework, a standard graph-based model for representing and linking data.
* **[OWL](https://en.wikipedia.org/wiki/Web_Ontology_Language)**: Web Ontology Language, used to formally represent ontologies and relationships between concepts.
* **[RDFa](https://en.wikipedia.org/wiki/RDFa)**: Method for embedding RDF metadata within HTML and other markup documents.
* **[SPARQL](https://en.wikipedia.org/wiki/SPARQL)**: Query language and protocol for querying RDF graphs.
* **[Triple store](https://en.wikipedia.org/wiki/Triplestore)**: Database designed for storing and querying RDF triples.
* **[Semantic MediaWiki](https://en.wikipedia.org/wiki/Semantic_MediaWiki)**: MediaWiki extension that adds structured semantic data and querying.
* **[GRDDL](https://en.wikipedia.org/wiki/GRDDL)**: W3C standard for extracting RDF data from XML and HTML documents.
## Overview
W3C maintains a community-created collection of tools for developing Semantic Web applications. It includes development environments, editors, libraries, reasoners, browsers, converters and other infrastructure rather than Semantic Web applications themselves.
