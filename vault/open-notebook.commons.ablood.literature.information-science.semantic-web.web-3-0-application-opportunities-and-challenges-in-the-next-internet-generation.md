# [Web 3.0: Applications, Opportunities and Challenges in the Next Internet Generation](https://onlinelibrary.wiley.com/doi/abs/10.1002/sres.3151)

## Terms
- **Web 3.0**: In this paper, an umbrella term combining Semantic Web technologies, AI, IoT, and blockchain (rather than only the original Semantic Web).
- **dApp**: Decentralized application running on a blockchain.
- **Smart contract**: Self-executing program on a blockchain.
## Intro
The paper treats Web 3.0 as the convergence of Semantic Web technologies, AI, blockchain, and IoT.
For my research, the Semantic Web aspects are much more relevant than the blockchain discussion.
## Relevant to my research
- Ontologies provide structured representations that allow machines to understand relationships between data.
- Linked data enables heterogeneous datasets to be connected into a richer semantic graph.
- Semantic technologies improve interoperability between independently managed datasets.
- Semantic representations support richer information retrieval and decision making.
- AI benefits from semantically structured data through improved context and integration.
## Relevant Takeaway
- The paper largely conflates the original Semantic Web with the modern blockchain-centric "Web3" movement.
- The strongest ideas for my work are the emphasis on ontologies, linked data, semantic interoperability, and heterogeneous data integration—not cryptocurrency or decentralization.
